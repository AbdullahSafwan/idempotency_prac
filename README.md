## Idempotency Practice

This repository contains a simple implementation of idempotency in a Node.js application using Redis as the storage mechanism. The application demonstrates how to handle duplicate requests gracefully by ensuring that the same request is processed only once.

## How to run

1. Clone the repository:
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the Redis server (make sure you have Redis installed and running):
   ```bash
   redis-server
   ```
4. Start the application:
   ```bash
   npm start
   ```
